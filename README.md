### 🚀 About Me

- 🔧 I build IoT products **end to end**: KiCad PCBs → ESP32 firmware (ESP-IDF, FreeRTOS) → wireless links (BLE, ESP-NOW, nRF24) → Flutter apps. One person, many hats, zero sleep.

- 🔐 Currently learning **Hardware & IoT Security**: eJPT v2 in progress, cryptography CTFs on CyberTalents, Fortinet track at NTI (95%). I design the UART, SPI and I²C pins attackers love to poke… so now I'm learning to poke them too.

- 🎓 B.Sc. Electronics & Communication Engineering, MIU 2026, **ranked 1st in class all five years**.

- 💬 Ask me about **ESP32, FreeRTOS, PCB design, wireless protocols, Robotics, C/C++ and Python.** My toolbox is still overflowing.

- 📫 How to reach me? **zeyad20hisham@gmail.com**. Whether you want to discuss tech or share memes, I'm here.
